# Start JARVIS v28.1

1. Keep V26/V27/V28 folders as backups.
2. Extract this ZIP to `C:\Users\austi\Desktop\Jarvis_v28_1`.
3. Double-click `START_JARVIS_V28_1.cmd`.
4. On first run it creates `.venv` and installs requirements. Later starts are one click.
5. Confirm the top bar says **v28.1 · HOLO CORE**. If it does not, stop and report what it shows.

## Language
V28.1 starts in **English**. Settings can later be changed to Auto or Hebrew intentionally.

## HoloLab
Switch workspace to **HoloLab**, enable Camera, then press **Enter HoloLab**.
The hologram must appear even when hand tracking is unavailable. Mouse/touch drag and mouse wheel scaling are the fallback controls.

## Phone
Keep the secure `https://...ts.net` URL. Keep the PC's Tailscale IPv4 in the fallback-IP field.
Build/install the updated companion by double-clicking `BUILD_PHONE_V28_1.cmd`.
After pairing + START, JARVIS can use:
- native phone calendar read
- phone battery/charging
- device info
